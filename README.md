Tank Battle（ゲーム）
2025年 7月 - 2025年 9月

使用した技術：C#、Unity、photon(Unityのライブラリ)

本作は、心理戦と読み合いを重視した対戦ゲームです。
元々はゼミで制作したカードゲームをベースとしており、デジタルゲーム化するにあたって、カードの代わりにキャラクター同士が戦う方がより直感的で面白いと考え、カードを3Dタンクモデルとして表現しました。
プレイヤーはタンクをカードの代わりに配置し、攻撃・防御・コスト管理を考えながら相手の行動を予測し、勝利を目指します。
同時選択とターン制の仕組みにより、「相手が何を出すか」を読む駆け引きがゲームの核となっています。
相手が何枚タンクを出すかは分かりますが、どのタンクを出すかまでは分からないため、
限られた情報の中で相手の戦略を推測し、自分の選択を決める心理的な駆け引きを強く意識したゲームデザインになっています。
